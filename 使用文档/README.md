# 暑假学习计划工具

一款基于单文件 HTML 的暑假学习计划管理工具。

## 📁 文件结构

```
使用文档/
├── index.html          # 主应用（双击打开即可使用）
├── 创意提案.html       # 项目创意提案
└── README.md           # 使用说明
```

## 🚀 快速开始

**打开方式**：双击 `index.html` 文件即可在浏览器中运行。

**核心功能**：
- 📋 智能文字识别（粘贴文本自动分类）
- 📊 精美导出（多工作表 Excel）
- 💾 自动保存（刷新页面自动恢复）
- ↩️ 操作回退（Ctrl+Z/Ctrl+Y）
- 📱 响应式设计（桌面/移动端）
- 🌙 主题切换（明暗模式）

## 📖 使用方法

1. **直接编辑**：在页面上填写阶段目标、本周重点、待办清单、时间轴、习惯打卡、周复盘
2. **粘贴文本**：点击左侧「粘贴文本」按钮，按格式粘贴文字，系统智能识别分类
3. **导出计划**：点击顶部「📊 导出Excel」或「💾 备份数据」按钮

## 📝 文字版计划写法

直接按以下格式写文字，粘贴后系统自动识别分类：

### 完整格式示例

```
目标：暑假实现学科查漏补缺，每日学习6小时，每周运动3次，完成2本课外书阅读，每日复盘总结

重点：
1. 完成当日学习计划
2. 运动30分钟以上
3. 睡前复盘当日得失

待办：
- 整理当日错题本
- 背诵20个英语单词
- 阅读课外书30分钟
- 复习上周内容

习惯打卡：
早起：周一、周三、周五、周日
运动：周二、周四、周六
阅读：每天
学习：周一至周五
复盘：每天

时间：
07:00-07:30 每天：晨起+早餐+复盘昨日
08:00-10:00 周一：数学复习 | 周二：英语阅读 | 周三：物理实验 | 周四：语文写作 | 周五：化学刷题 | 周六：图书馆自习 | 周日：休息
10:15-12:00 周一至周五：副科知识点梳理+练习 | 周六：兴趣学习 | 周日：家庭时间
12:00-14:00 每天：午餐+午休
14:30-16:30 周一：英语听力 | 周二：数学练习 | 周三：编程学习 | 周四：英语写作 | 周五：物理复习 | 周六：运动 | 周日：自由活动
16:45-17:45 周一至周五：运动/户外活动 | 周六：游泳 | 周日：散步
19:00-20:30 每天：课外书阅读+笔记
20:45-21:30 每天：当日复盘+明日计划

成就：本周完成了数学复习前三章，英语单词背诵500个，阅读完《活着》

下周：继续复习数学第四章，开始英语四级备考，阅读《百年孤独》
```

### 各栏目说明

| 栏目 | 格式要求 | 示例 |
|------|----------|------|
| 目标 | `目标：内容` | `目标：暑假学习计划` |
| 重点 | `重点：` 后接列表 | `重点：\n1. 完成学习计划\n2. 运动` |
| 待办 | `待办：` 后接列表 | `待办：\n- 背单词\n- 阅读` |
| 习惯打卡 | `习惯打卡：` 后接习惯名和打卡日期 | `习惯打卡：\n早起：周一、周三` |
| 时间 | `时间：` 后接时间安排 | `时间：\n08:00 学习` |
| 成就 | `成就：内容` | `成就：完成复习` |
| 下周 | `下周：内容` | `下周：继续学习` |

### 支持的列表格式

```
1. 内容              # 数字序号
2. 内容
- 内容               # 破折号
• 内容               # 圆点（•）
● 内容               # 实心圆（●）
[ ] 内容             # 方括号
1 内容               # 纯数字（无点号）
```

### 支持的时间格式

```
08:00-10:00 学习     # 时间段（推荐）
08:00 学习           # 时间点
8点30 学习           # 中文时间
8时 学习             # 中文时间
```

### 习惯打卡日期格式

```
早起：周一、周三、周五    # 指定星期几
运动：周二、周四、周六    # 指定星期几
阅读：每天              # 每天都打卡
学习：周一至周五         # 周一到周五
```

### 智能识别规则

系统会自动识别以下关键词并分类：

| 分类 | 支持关键词 |
|------|-----------|
| 目标 | 目标、goal、objective、target、暑假目标、学习目标 |
| 重点 | 重点、flag、priority、focus、核心任务、主要任务 |
| 待办 | 待办、todo、task、checklist、待办事项、任务清单 |
| 习惯 | 习惯、habit、routine、日常、打卡、习惯打卡 |
| 时间 | 时间、schedule、timetable、日程、安排、作息表 |
| 成就 | 成就、achievement、summary、收获、成果、总结 |
| 下周 | 下周、next week、下周计划、下周安排 |

### 导入方法

1. **粘贴文本**：点击左侧「📋 粘贴文本」按钮，在弹出的对话框中粘贴文字，点击「确认导入」
2. **智能识别**：系统自动识别关键词并分类填充到对应区域
3. **手动调整**：导入后可手动修改任意内容

## 📊 导出功能

### Excel导出（时间轴）

导出单个工作表「每日时间轴」，包含：
- 时间列 + 周一至周日列
- 合并单元格标题
- 使用说明

文件名：`暑假时间轴_日期.xlsx`

### Word导出（时间轴）

导出精美格式的Word文档，包含：
- 蓝色标题「暑假每日时间轴」
- 完整7天时间轴表格
- 周六周日浅蓝色高亮
- 使用说明

文件名：`暑假时间轴_日期.doc`

### Word导出（小日记）

在小日记区域点击「📄 导出日记」按钮，生成Word文档，包含：
- 日期、天气、心情信息
- 今日记录内容
- 本周成就、下周计划

文件名：`暑假日记_日期.doc`
